#  Vehicle Market Analysis Dashboard

##  Project Overview

This project presents an interactive Power BI dashboard for analyzing the automobile market. The dashboard explores vehicle pricing, performance, fuel economy, and manufacturer comparisons using interactive visualizations and DAX calculations.

##  Business Objectives

This dashboard answers the following questions:

- Which manufacturers produce the most expensive vehicles?
- How does engine size influence vehicle price?
- Which manufacturers deliver the highest performance?
- Which vehicles are the most fuel-efficient?
- Which manufacturer performs best overall using a Manufacturer Performance Index (MPI)?


##  Dashboard Pages

###  Executive Dashboard

Provides an overview of the automobile market with KPIs and summary charts.

###  Pricing Analysis

Explores vehicle pricing, premium manufacturers, and pricing trends.

###  Performance Analysis

Analyzes horsepower, engine size, and vehicle performance.

###  Fuel Economy Analysis

Examines fuel efficiency across manufacturers, body styles, and fuel types.

###  Manufacturer Comparison

Compares manufacturers using a custom Manufacturer Performance Index (MPI).
